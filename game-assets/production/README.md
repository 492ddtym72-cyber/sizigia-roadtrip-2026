# Production game assets

Upload the final high-resolution game artwork using these exact paths:

- `backgrounds/game-background.webp`
- `sprites/psy-bird.png`
- `sprites/psy-pillar.png`

Requirements:

- `game-background.webp`: portrait artwork, no UI, bird, or pillars.
- `psy-bird.png`: transparent PNG, facing right, with padding around the sprite.
- `psy-pillar.png`: transparent PNG, tall vertical obstacle with a clean silhouette.

The `ui/` and `effects/` directories are reserved for future additions and can remain empty.
